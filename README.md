## Introduction
This project contains three simple website interfaces created using HTML and CSS. Each case study uses a separate HTML file and a separate CSS file.

## Case Study 4: Student Academic Dashboard
**Files:** `4.html`, `4.css`

### Objective
To create a basic student dashboard that presents academic information in a clear layout.

### Features
- Academic overview cards for attendance, subjects and pending tasks.
- Subject table showing sample internal marks and status.
- Announcements section.
- Navigation links to page sections.
- Responsive layout for smaller screens.

### Technologies Used
- HTML for page structure.
- CSS for layout, colours, cards, table and responsive styling.

**Note:** In `4.html`, update the stylesheet link from `3.css` to `4.css` so it uses the matching CSS file.

## Case Study 5: Digital Library
**Files:** `5.html`, `5.css`

### Objective
To design a simple digital library page where users can view book categories, featured books and library rules.

### Features
- Welcome section.
- Book categories such as Programming, Web Design, Science and Fiction.
- Featured book cards with author names and availability status.
- Library rules section.
- Responsive book-card layout.

### Technologies Used
- HTML for content and sections.
- CSS for colours, book cards, status labels and responsive design.

## Case Study 6: ShopSmart Online Store
**Files:** `6.html`, `6.css`

### Objective
To create a basic online shopping interface that displays popular products and a promotional offer.

### Features
- Header navigation with Home, Products and Offers links.
- Promotional banner and Shop Products link.
- Special-offer section.
- Product cards for a smartphone, headphones and a smart watch.
- Sample product prices and ratings.
- Responsive layout for mobile screens.

### Technologies Used
- HTML for the website structure.
- CSS for the banner, product cards, buttons, colours and responsive styling.

## How to Run the Websites
1. Keep each HTML file and its matching CSS file in the same folder.
2. Check that each HTML file links to the correct CSS file:
   - `4.html` → `4.css`
   - `5.html` → `5.css`
   - `6.html` → `6.css`
3. Double-click an HTML file to open it in a web browser.

## Conclusion
These three case studies demonstrate the use of basic HTML elements, navigation links, sections, tables, cards and CSS styling. They are beginner-friendly examples of building different website layouts without JavaScript.
